# Berly Landing Page

Marketing landing page for [Berly](https://berly.app) — AI compliance documentation software.

## Structure
- `index.html` — single-file landing page (CSS and JS embedded)
- `assets/` — images and icons
- `classifier.html` — free AI risk classifier (coming soon)

## Deployment
Deployed to Cloudflare Pages at berly.app.

## Development
Open index.html directly in a browser. No build step required.
